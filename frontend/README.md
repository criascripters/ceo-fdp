# Front-end do CEO fdp

Esta é a implementação da página de submissão da SUA COBRANÇA ao Daniel e ao Ítalo através do CEO fdp. Um formulário
simples com uma lista de mensagens enviadas à direita é tudo o que você precisa para contribuir ao nosso Duolingo da
programação.

Este projeto foi construído com:

- ReactJS 🤓
- TailwindCSS
- shadcn/ui
- Vite

## Executando o projeto

Primeiro você deve instalar as dependências do projeto:

```bash
npm i
```

Depois basta inicializar o Vite:

```bash
npm run dev
```

e você terá o projeto executando em `http://localhost:5173`.
