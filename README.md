# P.O. arrombado

Bot do discord + página web para cobrar o Daniel e o Ítalo terminarem o Duolingo de programação.

## Organização do projeto

O projeto possui dois sub-projetos principais:

- `api` - API feita com express.js e MongoDB
- `frontend` - Páginas feitas com ReactJS + TailwindCSS + Shadcn

Para maiores informações de cada projeto, acesse os READMEs em suas pastas.
